superkitty

Le terminal de Claude Code

Un vrai terminal macOS — vrai PTY, n'importe quel shell — pensé friction-first pour vivre avec un agent qui tourne. Ferme la fenêtre : la session ne s'éteint pas.

00 Ce que ça fait /usr/share/man/superkitty.1

kitty est un chat. superkitty en est la version à neuf vies : chaque terminal est adossé à une session tmux, donc le run Claude vit dans le serveur tmux, pas dans la fenêtre. Tu fermes, tu rouvres — le run continue.

  • [x]Sessions persistantes. Adossées à tmux new-session -A -D : fermer la fenêtre détache, ne tue jamais. Rouvrir réattache le run Claude vivant + tout le scrollback.
  • [x]Onglets & panes. Layouts façon kitty — tall · fat · grid · horizontal · vertical · stack — recalculés et auto-équilibrés à chaque ajout/fermeture.
  • [x]Drag & drop d'images. Le chemin est injecté en bracketed-paste → Claude affiche [Image #1]. Idem pour le coller d'image ⌘V.
  • [x]Palette de commandes. Fuzzy, toutes les actions + sessions tmux. ⌘K
  • [x]Sélecteur de fichiers git-aware ⌘P, compositeur de prompt multi-ligne ⌘E, bloc-notes par onglet ⌃⇧N.
  • [x]Sidebar de sessions. Liste/attache toutes les sessions tmux. ⌘B
  • [x]Dropdown Quake global. Depuis n'importe quelle app : choisis un projet, tape, ↵. ⌃`
  • [x]Notifications agent-fini. Détectées sur le BEL, notif macOS native quand Claude a terminé.
  • [x]Sandbox par pane. Écritures confinées au dossier projet (profil Seatbelt, lectures ouvertes).
  • [x]Rouvrir un pane/onglet fermé. Réattache la session vivante ou recrée l'onglet à l'identique. ⌘⇧T
  • [~]Poignées de redimensionnement draggables — layouts auto-équilibrés pour l'instant.
